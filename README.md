# Trash Titans website

A portable static website for Trash Titans. No build command or package installation is required.

## Put it on GitHub

1. Download and unzip the package.
2. Upload everything inside the `trash-titans-website` folder to the root of your repository.
3. Commit the files to the repository's default branch.

## Publish with GitHub Pages

1. Open the repository's **Settings**.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the default branch and the `/ (root)` folder, then save.

## Contact form

Quote requests are sent to `kristoffershore@gmail.com` through FormSubmit. The first submission may send a one-time activation email to that address. Open it and confirm the form before relying on it for customer leads.

## Custom domain

After GitHub Pages is working, add your domain under **Settings → Pages → Custom domain**. GitHub will show the DNS records needed at your domain registrar.
